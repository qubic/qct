## Context — two-proposal structure

The goal is a **sustainable finance structure** for QCT: predictable monthly spending, no repeat of the June 2026 shortfall, and no risk that user-facing services stop if any single quarterly vote fails.

**Base Services Reserve — approved.** The companion [Base Services Reserve proposal](./2026-09-15-Base-Services-Reserve-proposal.md) (190B QUBIC, 15 months, Oct 2026 – Dec 2027) has been **accepted by computor vote**. That locks in a minimum baseline for the public apps (Explorer, Wallet, Proposals, Docs), RPC/API, archiver, basic test net + test nodes, and infrastructure through end of 2027 — independent of any single quarterly vote.

**This proposal (Q4 2026 operational delta) — 450B QUBIC.** Adds the full Core, Integration, Testing, Management, and Client/Frontend teams **on top of** the accepted base, for the 3 Q4 months only. If approved, QCT operates at full team velocity through Q4. If not approved, the accepted base continues to keep the Main Net and its user-facing apps online, but active development, advanced testing, and community operations pause for the period.

## Scope changes vs. Q3

**Scope additions.** After removing smart-contract work entirely from Core scope in Q3, we are re-introducing a **bounded set of protocol-adjacent SC responsibilities** back into scope for Q4:

- **Qubic Guardian Network** — QCT drives the **ongoing development** of the Guardian Network software (lite and bob nodes) and handles a **small core-operations slice**. The bulk of Guardian Network operations and the Guardians program itself remain separately funded.
- **Infrastructure smart contracts** — QCT builds and maintains protocol-level infrastructure SCs (e.g., SWATCH-adjacent utilities, GQMPROP tooling). User-application SCs remain ecosystem-authored.
- **OM / OC sample contracts and apps** — QCT ships reference contracts and example applications for Oracle Machine and Outsourced Computing so ecosystem developers have concrete patterns to build against.
- **Protocol-level code review of ecosystem SCs** — QCT performs high-level review of ecosystem smart contracts for **protocol conformance** (correct QPI usage, restricted-dialect rules, resource limits). SC business-logic review remains the proposer's responsibility.

These additions are absorbed inside the Core and Testing lines below — they do not raise the monthly total above the tightened Q4 target.

**Budget tightening — driven by Q3 actuals, not scope changes:**

- **Management** ($18K → $13K/month): actual Jul/Aug run rate is ~$9.3K/month. Q4 keeps modest headroom for PMO/BD reserve and incubation management above the actual, but well below Q3 target.
- **Integration** ($12K → $6K/month): actual Jul/Aug run rate is ~$4.6K/month. Reduced to reflect current headcount with buffer.
- **Core** ($40K → $35K/month): accommodates the raika sternensucher → 100% Developer back-fill.
- **Testing Services** (~$3.5K → ~$2.5K/month within Infrastructure).
- **Infrastructure** ($6.5K → $5.2K/month total, with $3K in base + $2.2K in delta).
